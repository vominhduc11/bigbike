## 1. Kết luận cho chủ shop

Hệ thống **chưa sẵn sàng để coi là an toàn hoàn toàn cho production**. Audit xác nhận **62 finding**:

| Severity | Số lượng | Ý nghĩa |
|---|---:|---|
| **Blocker** | **1** | Có thể chiếm quyền xem đơn khách vãng lai và PII bằng cách đổi email |
| **High** | **21** | Sai đơn/giá/tồn kho, mất media, cam kết hoàn tiền sai, workflow bán hàng/xác thực/thông báo đứt gãy, rủi ro bảo mật đáng kể |

| **Tổng** | **62** | Chỉ tính finding còn đứng vững sau kiểm tra chéo |

### Rủi ro cần ưu tiên

1. **Rò rỉ dữ liệu đơn hàng:** tài khoản đã xác minh có thể đổi sang email khác nhưng vẫn được coi là đã xác minh; lần đăng nhập sau có thể nhận toàn bộ guest order của email mới (AUD-001).
2. **Sai đơn/sai giá và bán hàng đã tắt:** quick-buy nhận biến thể thuộc sản phẩm khác; <code>forceOutOfStock</code> không chặn biến thể (AUD-002, AUD-003).
3. **Mất file dùng chung:** xoá vĩnh viễn một bài viết có thể xoá object MinIO vẫn đang được sản phẩm dùng (AUD-004).
4. **Tự huỷ đơn và cam kết tài chính ngoài tài liệu:** job tự huỷ BACS 72 giờ không có rule chuẩn; email huỷ đơn hứa hoàn tiền 3–5 ngày dù refund đã gỡ (AUD-005, AUD-006).
5. **Thông báo quản trị không bảo đảm:** cache lộ chéo tài khoản, trạng thái đã đọc dùng chung cho mọi admin, backlog trên 30 sự kiện bị mất dù DB đánh dấu đã đọc (AUD-017–AUD-019).
6. **Song ngữ/SEO chưa vận hành đúng:** danh sách EN bị giữ dữ liệu VI, trang tĩnh không có nội dung EN, URL EN trong sitemap không phải trang EN ổn định (AUD-013–AUD-015).
7. **Hai workflow xác thực bị gãy theo đường Compose chuẩn:** link mời admin trỏ localhost và toàn bộ cấu hình Google/Facebook OAuth không vào container backend (AUD-061, AUD-062).

Điểm đã kiểm tra tốt trong pass này: build web thành công; test web **208/208** và admin **114/114** đều qua; locale VI/EN không lệch key; không phát hiện API caller admin trỏ tới endpoint không tồn tại; code địa chỉ mới đã dùng mô hình **tỉnh/thành → phường/xã**; listing hero, customer admin, audit log, dashboard và reports không lộ thêm lỗi material.

## 2. Phương pháp và mức độ tin cậy

- Trace workflow từ UI → API/BFF → controller → service → entity/migration → response → render.
- So sánh với <code>MODULE_CATALOG.md</code>, <code>BUSINESS_RULES.md</code>, <code>STATE_MACHINES.md</code>, <code>WORKFLOW_OVERVIEW.md</code>, <code>API_FLOW_MAP.md</code>, <code>API_CONTRACT.md</code>, <code>DATA_CONTRACT.md</code>, <code>PERMISSION_MATRIX.md</code>, <code>ARCHITECTURE.md</code>, <code>DEPLOYMENT_GUIDE.md</code> và <code>INTEGRATION_GUIDE.md</code>.
- Rà controller/caller, DTO/normalizer, permission gate, loading/error/empty state, locale, media URL, env, CSS/token, removed-feature residue và OpenAPI.
- Chạy:
  - web: <code>npm test</code> — 25 file, 208 test qua; <code>npm run lint</code> — 0 error/6 warning; <code>npm run build</code> — thành công, 39 static pages;
  - admin: <code>npm test -- --run</code> — 11 file, 114 test qua; <code>npm run lint</code> — qua;
  - dependency: admin 0 vulnerability; web <code>npm audit --omit=dev</code> báo 13 vulnerability (3 High, 9 Medium, 1 Low);
  - locale parity: web VI/EN cùng 1.163 leaf key; admin VI/EN cùng 2.929 leaf key;
  - encoding scan: không có mojibake ở web/admin; còn một chuỗi mojibake trong comment importer backend (AUD-054).
- Không chạy backend test suite hoặc runtime stack. Những test backend có dấu hiệu stale được đọc tĩnh và ghi riêng ở AUD-046.

### Quy ước verdict

- **code bug:** code hiện tại lệch canonical docs hoặc tạo hành vi sai có bằng chứng.
- **docs sai:** code/contract hiện tại nhất quán nhưng canonical docs còn mô tả hành vi cũ.
- **dead code/contract:** surface không còn consumer/implementation hoặc chỉ là residue.
- **cần owner quyết:** bằng chứng thật sự mâu thuẫn hoặc rule phá huỷ chưa có trong docs; audit không tự chọn đáp án.
